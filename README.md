# Wrinkle Guide — シワ描画補助ツール

3Dレンダー画像を読み込み、アンカーポイントを手動配置し、**カメラ角度パラメータに応じてシワガイドの形状・見え方がリアルタイムに変化するオーバーレイ**を表示するブラウザツールです。

3D→2Dイラスト変換ワークフローで「シワをどこに・どの方向に・何本」描くべきかの判断を補助します。シワガイドは内部的に3D曲線として計算され、指定したカメラ角度（方位角・仰角）で2Dに投影されるため、短縮・回り込み・可視/不可視が角度に応じて変化します。

## 使い方

1. **画像読込** — 3Dレンダー画像（PNG/JPEG）をドラッグ&ドロップまたはボタンで読み込む（お試しは「デモ画像」ボタン）
2. **カメラ角度** — この画像をどの角度から撮ったかを方位角・仰角スライダーで指定
3. **アンカー配置** — キャンバスをクリックして配置
   - 固定点（赤）: 肩先・袖口・裾・ボタンなど → 固定点ペア間に**張力ジワ**、上に**たまりジワ**
   - 関節点（青）: 肘・膝など。曲げ角度スライダー付き → 曲げ内側に**圧縮ジワ**
   - 支持点（緑）: 肩の頂点など布がかかる場所 → 下方向に**落ちジワ**
   - パーツラベルを選ぶとカメラ角度から深度を自動推定
4. **素材プリセット** — Tシャツ/デニム/シルクなど7種。硬さ・厚み・重さは手動調整も可
5. **PNG書出** — シワガイドのみを透過PNGで書き出し（解像度は入力画像と同一）

### ショートカット

| キー | 操作 |
|---|---|
| `A` | アンカー配置モード |
| `V` | 選択/移動モード |
| `Tab` | ガイド表示切替 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | Undo / Redo |
| マウスホイール | ズーム |
| `Space`+ドラッグ | パン |
| 右クリック | アンカー削除 |

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # dist/ にビルド
npm run preview  # ビルド結果のプレビュー
```

技術スタック: React + TypeScript + Vite、HTML5 Canvas 2D、自前の回転行列+弱透視投影（Three.js不使用）。サーバー不要のブラウザ完結型です。

## デプロイ

`main` ブランチへの push で GitHub Actions が自動ビルドし、ビルド結果を `gh-pages` ブランチへ公開します。

初回のみ、リポジトリの **Settings → Pages → Source** で「Deploy from a branch」を選び、ブランチに **`gh-pages` / (root)** を指定してください。以降は push のたびに自動更新され、`https://kuokuo4771.github.io/ClaudeTest2/` で公開されます。
