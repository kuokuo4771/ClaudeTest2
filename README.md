# Wrinkle Guide — シワ描画補助ツール

3Dレンダー画像を読み込み、アンカーポイントを手動配置し、**カメラ角度パラメータに応じてシワガイドの形状・見え方がリアルタイムに変化するオーバーレイ**を表示するブラウザツールです。

3D→2Dイラスト変換ワークフローで「シワをどこに・どの方向に・何本」描くべきかの判断を補助します。シワガイドは内部的に3D曲線として計算され、指定したカメラ角度（方位角・仰角）で2Dに投影されるため、短縮・回り込み・可視/不可視が角度に応じて変化します。

## 🚀 起動方法（インストール・ターミナル不要）

- **方法1: HTMLファイルを開くだけ** — リポジトリ直下の [`wrinkle-guide.html`](./wrinkle-guide.html) をダウンロードして、ブラウザで開く（ダブルクリック）だけで動きます。全機能が1ファイルに入っています。
- **方法2: Webで開く** — GitHub Pages を有効化すると https://kuokuo4771.github.io/ClaudeTest2/ で使えます（初回のみ Settings → Pages → Source を「Deploy from a branch」→ `gh-pages` / (root) に設定）。

## 使い方

1. **画像読込** — 3Dレンダー画像（PNG/JPEG）をドラッグ&ドロップまたはボタンで読み込む（お試しは「デモ画像」ボタン）
2. **カメラ角度** — この画像をどの角度から撮ったかを方位角・仰角スライダーで指定
3. **服の領域を囲む（推奨）** — `R` キーまたは「領域」ボタンで服の輪郭をクリックで囲む
   - シワガイドが**領域の中だけ**に表示され、服からはみ出さない
   - シワの回り込みの丸み（円筒半径）が**その高さでの服の幅に自動フィット**する
   - 透過背景のPNGなら、領域未指定でもキャラの形状で自動クリップされる
4. **アンカー配置** — キャンバスをクリックして配置
   - 固定点（赤）: 肩先・袖口・裾・ボタンなど → 固定点ペア間に**張力ジワ**、上に**たまりジワ**
   - 関節点（青）: 肘・膝など。曲げ角度スライダー付き → 曲げ内側に**圧縮ジワ**
   - 支持点（緑）: 肩の頂点など布がかかる場所 → 下方向に**落ちジワ**
   - パーツラベルを選ぶとカメラ角度から深度を自動推定
5. **素材プリセット** — Tシャツ/デニム/シルクなど7種。硬さ・厚み・重さは手動調整も可
6. **PNG書出** — シワガイドのみを透過PNGで書き出し（クリップ適用済み・解像度は入力画像と同一）

### シワ線の表現

ガイド線は均一な線ではなく、実際にペンで描くときと同じ**入り抜きのあるテーパー線**で表示されます。

- **張力ジワ（赤）**: 引っ張り元が太く先で抜ける。柔らかい布ではY字分岐が発生
- **圧縮ジワ（青）**: 中央の折り目ほど太く深く、端は浅い弧。深い曲げ（100°超）ではエコー線が付く
- **たまりジワ（緑）**: 硬い布は三角波（Z字）、柔らかい布は正弦波
- **落ちジワ（紫）**: 支持点側が太く、裾に向かって抜けるドレープ線

### ショートカット

| キー | 操作 |
|---|---|
| `A` | アンカー配置モード |
| `V` | 選択/移動モード |
| `R` | 服の領域モード（`Enter`で確定 / `Esc`で取消 / 右クリックで頂点・領域削除） |
| `Tab` | ガイド表示切替 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | Undo / Redo |
| マウスホイール | ズーム |
| `Space`+ドラッグ | パン |
| 右クリック | アンカー削除 |

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # dist/index.html に単一ファイルでビルド
npm run preview  # ビルド結果のプレビュー
```

技術スタック: React + TypeScript + Vite（vite-plugin-singlefile で単一HTML化）、HTML5 Canvas 2D、自前の回転行列+弱透視投影（Three.js不使用）。サーバー不要のブラウザ完結型です。

`wrinkle-guide.html` はビルド成果物のスナップショットです。ソースを変更したら `npm run build && cp dist/index.html wrinkle-guide.html` で更新してください。

## デプロイ

`main` ブランチへの push で GitHub Actions が自動ビルドし、ビルド結果を `gh-pages` ブランチへ公開します。

初回のみ、リポジトリの **Settings → Pages → Source** で「Deploy from a branch」を選び、ブランチに **`gh-pages` / (root)** を指定してください。以降は push のたびに自動更新され、`https://kuokuo4771.github.io/ClaudeTest2/` で公開されます。
